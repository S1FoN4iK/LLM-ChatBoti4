# LLM-ChatBoti4

##  Запуск

1. **Клонируйте репозиторий**
   git clone https://github.com/S1FoN4iK/LLM-ChatBoti4/tree/LLM-ChatBoti4

2. **Установите зависимости**
pip install -r requirements.txt

3. **Создайте(внутри проекта) .env файл и введите туда то что ниже + вместо примера ваш токен от Llama 4 Maverick(free) полученный на Openrouter**
OPENROUTER_API_KEY=ПРИМЕР

4. **Запустите**
python main.py(файл с историей общения с моделью будет создан сразу после вашего первого запроса)


##  Обоснование выбора модели Llama 4 Maverick для задач чат-бота

В данном проекте для реализации чат-бота была выбрана модель **Meta: Llama 4 Maverick (free)**, доступная через OpenRouter. Ниже представлены ключевые причины выбора именно этой модели.

---

### 1. Современная архитектура LLaMA 4
**Llama 4 Maverick** — это одна из последних моделей от Meta AI, основанная на архитектуре LLaMA 4. Она сочетает:
- высокое качество генерации текста,
- относительная устойчивость к галлюцинациям,
- способность понимать и обрабатывать сложные запросы.

Однако даже ей пришлось писать системные инструкции для избежания галлюцинаций, но все же она держится лучше чем те кого я тестил в ходе разработки. Например модель от Mistral ai была устойчива даже к системным инструкциям и писала чушь.

---

### 2. Хорошая поддержка русского языка
- с системными инструкциями отлично и без ошибок отвечает на русском, чего не скажешь про остальных где иногда была даже смесь языков,
- демонстрирует грамотные и логичные ответы,
- подходит для построения диалогов, FAQ и болталок.

---

### 3. Быстрая и эффективная
**Llama 4 Maverick (free)** — это облегчённая версия Llama 4, ориентированная на:
- высокую скорость генерации ответов(Примерно на 30% медленней чем остальные что я пробовал, но лучше чуть медленее зато качественно и без галлюцинаций),
- минимальное время отклика,
- экономию вычислительных ресурсов на стороне сервера.

---

###  Вывод:
> Я выбрал **Meta: Llama 4 Maverick (free)**, потому что это — **современная, быстрая, бесплатная и достаточно интеллектуальная модель**, отлично подходящая для создания диалогового чат-бота с поддержкой русского языка, возможностью настройки и простой интеграцией через OpenRouter.
